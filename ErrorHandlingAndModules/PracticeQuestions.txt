//Practice — Error Handling and Modules

Challenge 1 — Custom Error Classes:
Create three custom error classes:

TimeoutError — element didn't appear within timeout
ValidationError — form validation failed
NetworkError — API call or navigation failed

Each should store: message, testName, timestamp.
Write a function simulateTest(type) that throws different errors based on type. Handle each differently in try/catch.

Challenge 2 — Retry Mechanism:
Write a retryOperation(fn, maxRetries, delayMs) function that:

Retries the function up to maxRetries times
Waits delayMs between attempts
Logs each attempt with attempt number
Returns the result if successful
Throws final error with attempt count if all fail

Test it with a function that randomly fails 70% of the time.
