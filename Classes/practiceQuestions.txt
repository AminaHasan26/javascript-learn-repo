// Practice — Classes

Challenge 1 — Your First Class:
Create a TestCase class with:

Constructor: name, priority, tags (array)
Properties: status = "pending", duration = 0, errorMessage = null
Methods: pass(duration), fail(duration, error), skip()
Method: printSummary() — prints all details formatted

Create 4 instances, call different methods on each, print all summaries.

Challenge 2 — Inheritance:
Create a Vehicle base class with make, model, year and methods start(), stop(), getInfo().
Extend it with:

Car class — adds doors, hasTrunk
Motorcycle class — adds hasSidecar, type ("sport" / "cruiser")

Create 2 cars and 2 motorcycles. Demonstrate inherited and own methods.

Challenge 3 — Static Methods:
Create a ValidationUtils class with only static methods:

isValidEmail(email) → boolean
isStrongPassword(pass) → boolean (8+ chars, has number, has special char)
isValidPhone(phone) → boolean (10 digits)
sanitize(text) → trims and lowercases
generateId(prefix) → returns "TC-001" style ID

Test each method directly on the class.

Challenge 4 — Getters:
Create a ShoppingCart class with:

Constructor: customerName, items = []
Method: addItem(name, price, qty)
Method: removeItem(name)
Getter: totalItems — total quantity of all items
Getter: subtotal — sum of price × qty
Getter: tax — 18% of subtotal
Getter: grandTotal — subtotal + tax
Method: printBill() — formatted receipt using getters


Challenge 5 — Full Page Object Preview:
Build these three classes:
BasePage — constructor takes pageName and url, has:

navigate() — prints navigation message
verifyTitle() — prints verification message
takeScreenshot(label) — prints screenshot message

LoginPage extends BasePage — has:

Locator properties: usernameInput, passwordInput, submitButton, errorText
fillUsername(value) — prints action
fillPassword(value) — prints action (mask with asterisks)
clickSubmit() — prints action
login(user, pass) — calls the three above in sequence
verifyError(message) — prints verification

HomePage extends BasePage — has:

verifyWelcome(name) — prints verification
clickLogout() — prints action
verifyMenuItems(items) — loops and prints each item verification

Write a function runSmokeTest(username, password) that creates both page objects and simulates a full login → verify → logout flow.
