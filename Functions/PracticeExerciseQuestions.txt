Challenge 2 — Validator Functions:
Write three separate arrow functions:

isNotEmpty(value) → returns true if value is not empty
isValidEmail(email) → returns true if email has @ and .
isStrongPassword(password) → returns true if 8+ chars and includes @ or # or !

Then write a fourth function validateForm(email, password) that uses all three and returns an appropriate message.

Challenge 3 — Calculator Functions:
Write these arrow functions:

add(a, b) → returns sum
subtract(a, b) → returns difference
percentage(value, total) → returns percentage rounded to 1 decimal
formatPrice(price) → returns price formatted as "₹1,299.00"

Then use them to calculate:
Cart Total    : ₹2,499.00
Discount(10%) : ₹249.90
Final Price   : ₹2,249.10
